# 中文 Stroop 测试

一个无需安装、可直接在浏览器中运行的 **中文版本 Stroop 自测网页**。

项目采用固定的 **5×5 中文色词矩阵**。测试时按照从左到右、从上到下的顺序，依次判断每个汉字的实际显示颜色，而不是汉字表达的颜色含义。

> 本项目在设计、代码实现与文档整理过程中使用了 OpenAI GPT 的辅助。

## Stroop介绍

Stroop 测试是一种经典的认知心理学实验，用于观察文字含义与文字颜色发生冲突时产生的干扰效应。本项目将其实现为简洁的中文网页版，通过 5×5 中文色词矩阵，引导用户依次判断文字的实际显示颜色，并提供计时、键盘或触屏作答、自行确认以及本地历史记录等功能，适合个人体验与教学演示。

## 在线体验

可通过[此链接](https://WhXcjm.github.io/chinese-stroop-test/)在线使用

## 功能

- 中文色词界面；
- 固定 5×5 测试矩阵，共 25 个项目；
- 按照从左到右、从上到下的顺序逐项测试；
- 当前项目高亮，已完成项目自动标记；
- 实时计时，完成第 25 项后自动停止；
- 八种颜色选项，两列排列；
- 支持鼠标、触屏和数字键 `1`～`8` 作答；
- 支持按数字键 `0` 或点击“我答对了”进行自行确认；
- 记录正确数、错误数、自行确认数和总用时；
- 历史记录保存在浏览器本地；
- 支持删除单条记录或清空全部记录；
- 自适应桌面端、平板和手机屏幕；
- 所有 HTML、CSS 和 JavaScript 均包含在单个 `index.html` 文件中。

## 使用方法

### 在线使用

打开 GitHub Pages 提供的网址，然后：

1. 点击“开始测试”；
2. 查看左侧矩阵中当前高亮的色词；
3. 判断该汉字的实际显示颜色，不要按照汉字含义作答；
4. 点击右侧颜色按钮，或按对应数字键 `1`～`8`；
5. 已经自行口头作答并确认正确时，可点击“我答对了”或按数字键 `0`；
6. 完成 25 项后，计时自动停止并显示结果。

### 本地使用

无需安装任何软件或依赖：

1. 下载仓库中的 `index.html`；
2. 在 Windows 11 中双击该文件；
3. 文件会使用默认浏览器打开；
4. 点击“开始测试”即可。

也可以将文件拖入 Chrome、Edge 或 Firefox 浏览器中运行。

## 按键说明

| 按键 | 操作 |
|---|---|
| `1`～`8` | 选择右侧对应的墨水颜色 |
| `0` | 声明当前项目回答正确 |
| 鼠标或触屏 | 点击相应按钮 |

数字键与颜色的具体对应关系会显示在每个颜色按钮下方。

## 项目结构

```text
chinese-stroop-test/
├── index.html
├── README.md
└── .nojekyll
```

- `index.html`：完整的中文 Stroop 测试网页；
- `README.md`：项目介绍和使用说明；
- `.nojekyll`：让 GitHub Pages 直接按静态文件发布仓库内容。

## 使用 GitHub Pages 部署

1. **Fork** 本仓库
3. 打开仓库的 **Settings**；
4. 在左侧选择 **Pages**；
5. 在 **Build and deployment** 中，将 **Source** 设为 **Deploy from a branch**；
6. Branch 选择 `main`，目录选择 `/ (root)`；
7. 点击 **Save**；
8. 部署完成后，在同一页面打开 GitHub 给出的访问地址。

项目页面地址通常为：

```text
https://你的GitHub用户名.github.io/chinese-stroop-test/
```

`index.html` 必须位于所选发布目录的最上层，否则可能出现 404 页面。

## 数据说明

测试历史使用浏览器的 `localStorage` 保存：

- 数据不会自动上传到服务器；
- 换用其他浏览器或设备后，原记录不会同步；
- 清除浏览器网站数据后，历史记录也会被删除；
- 使用无痕模式时，记录可能无法长期保留。

## 注意事项

本项目主要用于个人体验、教学演示和一般自测，不构成医学、心理学或临床诊断。

不同设备的屏幕亮度、色彩模式、环境光线以及色觉差异，都可能影响测试表现。
